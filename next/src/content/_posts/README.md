Post front matter tips for performance and social cards:

- Use `image` for the card/social image path (e.g. /assets/images/my-image.png)
- Add `image_width` and `image_height` in pixels for that image to avoid CLS

Example:

---
layout: post
title: "My Post"
date: 2026-02-11
image: /assets/images/my-image.png
image_width: 1200
image_height: 630
---
